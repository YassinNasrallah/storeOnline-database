# Online Store Database

## About the Project

This project is a simple online store database built with **MySQL**. It is designed to practice database creation, table relationships, and SQL queries.

The database organizes information about customers, products, employees, and orders.

## Database Structure

The database contains four tables:

- **Customers** — Stores customer information, including names, birth dates, and money spent.
- **Products** — Stores product categories and prices.
- **Employees** — Stores employee information.
- **Orders** — Stores order details and connects customers, employees, and products using foreign keys.

## Technologies Used

- MySQL
- SQL

## Concepts Practiced

- Creating databases and tables using `CREATE DATABASE` and `CREATE TABLE`
- Defining primary keys with `PRIMARY KEY`
- Generating IDs automatically with `AUTO_INCREMENT`
- Using data types such as `INT`, `VARCHAR`, `DATE`, and `DECIMAL`
- Inserting data with `INSERT INTO`
- Retrieving data with `SELECT`
- Connecting tables using `FOREIGN KEY`

## Getting Started

### Prerequisites

- MySQL Server
- A MySQL editor, such as MySQL Workbench or PopSQL

## Project Goal

The goal of this project is to build a foundation in relational database design and understand how SQL manages and connects data in a real-world scenario.
